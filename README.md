# أسعار الموبايلات والراوترات في العراق

برنامج يسحب أسعار الموبايلات والراوترات كل يوم من صفحات فيسبوك وإنستكرام ومواقع المحلات العراقية، ويعرضها بموقع فيه: اسم الجهاز، المواصفات، سعر اليوم (بالدينار أو الدولار مثل ما مكتوب بالمنشور)، ورابط المنشور أو الصفحة.

## شلون يشتغل
1. **المواقع العراقية**: البرنامج يسحبها تلقائياً كل يوم (Shopify و WooCommerce وأي صفحة فيها أسعار)، ويدور على مواقع جديدة ويقبل بس اللي تذكر مدينة عراقية أو رقم عراقي.
2. **فيسبوك وإنستكرام**: أنت تفتح الصفحات بمتصفحك بحسابك بشكل طبيعي، تنزل شوية، وتحفظ الصفحة بـ Ctrl+S داخل مجلد `inbox`. البرنامج ما يدخل على فيسبوك أبداً، يقرا الملفات المحفوظة بس، فحسابك يبقى آمن.
3. **القراءة**: `collector/parser.py` يطلع اسم الجهاز والمواصفات والسعر من النص، ويفهم "الف" و"مليون" و"$" و"ورقة" والأرقام العربية.
4. **الموقع**: مجلد `docs` ينشر مجاناً على GitHub Pages ويتحدث وحده بعد كل تشغيل.

## التنصيب (مرة وحدة)
1. نصّب Python من python.org (أشّر على Add Python to PATH) و Git من git-scm.com.
2. شغّل `setup.bat`.
3. شغّل `schedule_daily.bat` حتى يشتغل كل يوم الساعة 10 الصبح.

## كل يوم (دقيقتين)
1. افتح صفحات فيسبوك اللي تريدها (القائمة بـ `collector/config/sources.json`) ونزّل لحد ما تبين منشورات اليوم.
2. اضغط Ctrl+S واختار مجلد `inbox` واحفظ (أي نوع: Webpage, Complete أو Single File).
3. إما تستنى التشغيل اليومي، أو شغّل `run_now.bat` هسه.
الملفات المقروءة تنتقل لـ `inbox/done`.

## إضافة مواقع
عدّل `websites` بملف `collector/config/sources.json`. المواقع اللي يلگاها البحث التلقائي تنحفظ بـ `collector/config/discovered.json`، وتگدر تمسح أي وحدة منها.

## ملاحظات
- الأسعار المكتوبة داخل الصور تنقرا بقارئ ويندوز المجاني (OCR). احفظ الصفحة بنوع "Webpage, Complete" حتى تنحفظ الصور وياها. القارئ ممكن يغلط بالأرقام الصغيرة، فكل سعر من صورة مكتوب جنبه "[من الصورة]" ورابط المنشور حتى تتأكد.
- إذا المنشور ما ذكر العملة (مثلاً "السعر 850") يظهر "العملة غير مذكورة" بدل ما نخمن.
- ترتيب "الأرخص أولاً" يقارن الدولار بسعر تقريبي 1500 دينار بس للترتيب، والسعر المعروض يبقى مثل المنشور.
